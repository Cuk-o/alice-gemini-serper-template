# Яндекс Алиса + нейросеть + поиск на Vercel

Готовый шаблон вебхука для навыка Яндекс Алисы: нейросеть Groq, поиск в интернете через Exa (запасной — Serper), память в Upstash Redis. Вам не нужно редактировать код: разместите этот репозиторий в Vercel, добавьте API-ключи и укажите адрес вебхука в Яндекс Диалогах.

## Самый простой способ — Fork

1. На GitHub нажмите **Fork** и создайте свою копию репозитория.
2. Откройте https://vercel.com/dashboard и нажмите **Add New… → Project**.
3. В списке **Import Git Repository** выберите свою копию и нажмите **Import**.
4. Нажмите **Deploy** и дождитесь завершения первого развёртывания.
5. В проекте Vercel откройте **Settings → Environment Variables**.
6. Создайте переменные окружения ниже, выбрав **Production** для каждой:
   - **Key:** LLM_API_KEY — **Value:** ключ Groq: https://console.groq.com/keys
   - **Key:** EXA_API_KEY — **Value:** ключ Exa: https://dashboard.exa.ai
   - **Key:** ALICE_SKILL_ID — **Value:** ID навыка из Яндекс Диалогов (виден в адресе страницы навыка и в поле `session.skill_id` запроса в тестере)
7. После сохранения ключей откройте **Deployments** и выберите **Redeploy** для последнего Production-развёртывания. Дождитесь статуса **Ready**.
8. В Vercel откройте **Settings → Domains**, скопируйте свой домен и добавьте в конец /api. Например: https://YOUR-PROJECT.vercel.app/api.
9. Откройте свой навык в Яндекс Диалогах. В настройках Backend вставьте этот полный адрес в **Webhook URL** и сохраните изменения.
10. Включите опцию **Использовать хранилище данных в навыке**, чтобы сохранять контекст между репликами.

Названия разделов могут немного отличаться при обновлении интерфейса. Используйте только свой домен Vercel — не копируйте адрес автора шаблона.

## Если вы скачали ZIP

1. Распакуйте ZIP двойным кликом.
2. В своём GitHub нажмите **+ → New repository** и создайте репозиторий.
3. Откройте его и выберите **Add file → Upload files**.
4. Перетащите содержимое распакованной папки в браузер. Не потеряйте папку api и файл api/index.js внутри неё.
5. Нажмите **Commit changes**.
6. Вернитесь к шагу 2 в разделе выше и импортируйте репозиторий в Vercel.

## Какие ключи нужны

- **LLM_API_KEY** обязателен: ключ Groq (https://console.groq.com/keys), бесплатно и без карты. Groq отвечает за доли секунды. Лимиты бесплатного плана: около 30 запросов и 7000 входных токенов в минуту на модель, 1000 запросов в сутки; остаток виден на https://console.groq.com/settings/limits. Если основная модель упрётся в лимит, навык повторит запрос на запасной.
- **EXA_API_KEY** — основной поиск в интернете: https://dashboard.exa.ai, без карты, $10 бесплатных кредитов каждый месяц (~2500 поисков). Отвечает за ~0,6 с и отдаёт сниппеты с цифрами (погода, курсы).
- **SERPER_API_KEY** — необязательный запасной поиск через Google: используется, если Exa вернула ошибку (например, кончились кредиты месяца). 2500 бесплатных запросов даются один раз. Без ключей поиска навык отвечает без интернета.
- **ALICE_SKILL_ID** — рекомендуется: с ним вебхук отвечает только вашему навыку, и посторонние не потратят ваши лимиты.

Поиск выполняется на каждый вопрос, кроме реплик из одного слова вроде «привет» или «спасибо» и вопросов о самом пользователе («как зовут моего кота»). Уточняющие вопросы переписываются в полный запрос с учётом диалога («а когда он вышел?» → «дата выхода последнего фильма Marvel»), а вопрос про две темы ищется двумя параллельными запросами.

Подходит любая нейросеть с OpenAI-совместимым API:
- **LLM_API_URL** — полный адрес `/chat/completions`, по умолчанию Groq: `https://api.groq.com/openai/v1/chat/completions`. Например, Gemini: `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` (бесплатный Gemini часто отвечает дольше 4,5 секунды, которые даёт Алиса).
- **LLM_MODEL** — имя модели, по умолчанию `qwen/qwen3.8-27b`.
- **LLM_FALLBACK_MODEL** — модель для повтора при превышении лимита, по умолчанию для Groq `openai/gpt-oss-120b`.

### Память между разговорами (необязательно)

Без хранилища навык помнит только последние реплики текущего разговора (Яндекс ограничивает их объём 1 КБ). Чтобы он помнил и между запусками:

1. Vercel → проект → **Storage → Create Database → Upstash (Redis)**, регион **Frankfurt** (рядом с функцией), бесплатный план.
2. Подключите базу к проекту — переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами. Сделайте **Redeploy**.

Навык хранит последние 6 пар реплик и факты 30 дней. Команды: «запомни, что …» — сохранить факт; «забудь всё» — стереть память. Если база недоступна, навык работает как без неё. В логи Vercel записываются поисковые запросы, а значит, и тексты вопросов — учитывайте это, если делитесь доступом к проекту.

Ключи вводятся только в **Vercel → Settings → Environment Variables**. Не размещайте их в исходном коде, GitHub, README, Яндекс Диалогах или сообщениях. Если ключ попал в открытый доступ, отзовите его и создайте новый.

## Как проверить навык — без команд и программирования

**Самый простой способ — проверить его голосом на колонке или через приложение с Алисой.**

1. Убедитесь, что в Яндекс Диалогах у навыка указан ваш адрес Vercel в поле **Webhook URL**, который заканчивается на `/api`.
2. В настройках навыка выберите тип доступа **Приватный** и сделайте навык доступным для тестирования. Для голосового запуска войдите на колонке или в приложении с Алисой в тот же аккаунт Яндекса, которым вы пользуетесь в консоли разработчика.
3. Скажите: **«Алиса, запусти навык [название или активационное имя вашего навыка]»**. Например, вместо скобок произнесите настоящее название, которое вы указали в настройках навыка.
4. Когда Алиса запустит навык, задайте обычный вопрос и проверьте, что она отвечает.

Если Алиса не находит навык или вы ещё не сделали его доступным для голосового запуска, откройте Яндекс Диалоги → свой навык → **Тестирование**. Этот встроенный тестер подходит для первой проверки до публикации и показывает ответ навыка.

Если всё работает в тестере, но не работает через колонку, проверьте, что навык доступен для голосового запуска, на колонке выбран тот же аккаунт Яндекса и произносится правильное активационное имя. Инструкция Яндекса: https://yandex.ru/dev/dialogs/alice/doc/ru/test

## Если навык не отвечает

1. Проверьте, что имена переменных написаны без опечаток и выбрано окружение **Production**.
2. После изменения ключей выполните **Redeploy** и дождитесь статуса **Ready**.
3. Проверьте правильность **Webhook URL**: домен должен быть вашим, путь должен заканчиваться на /api.
4. Откройте последнее развёртывание в Vercel и проверьте логи. Перед отправкой логов в ChatGPT удалите из них секретные данные.

## Ограничение времени ответа

Яндекс Диалоги ожидают ответ от навыка не больше 4,5 секунды, включая сетевую задержку между Яндексом и Vercel. Поэтому шаблон ограничивает время поиска и генерации, чтобы не зависать на слишком долгом запросе. При медленном ответе нейросети сервер возвращает «Не успела подготовить ответ». Проверить скорость можно командой `npm run latency -- https://ВАШ-ПРОЕКТ.vercel.app/api` (нужен Node.js 22): она покажет общее время и время нейросети (`llm;dur`). Это помогает снизить число таймаутов, но не гарантирует полный ответ при медленной сети или высокой нагрузке.
